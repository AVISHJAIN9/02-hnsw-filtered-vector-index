# Design Note: 066 - Distance Metrics

## Overview
Feature #66 implements scalar microkernel distance metrics for `hnsw-simd`:
- **L2** (Squared Euclidean distance): $D_{L2}(a, b) = \sum_{i=0}^{d-1} (a_i - b_i)^2$
- **Cosine distance**: $D_{Cos}(a, b) = 1 - \frac{\sum a_i b_i}{\sqrt{\sum a_i^2}\sqrt{\sum b_i^2}}$
- **Inner Product distance**: $D_{IP}(a, b) = -\sum_{i=0}^{d-1} a_i b_i$

Dispatched via `hnsw_common::schema::Metric`.

## Error Handling
Returns typed `MetricError`:
- `DimensionMismatch { expected: usize, actual: usize }`
- `ZeroVector` (for Cosine when vector norm is zero)
- `NonFiniteFloat` (if input contains NaN or Infinity)

## Mathematical Properties
- **L2**: Non-negative ($[0, \infty)$), symmetric ($D(a, b) = D(b, a)$), identity of indiscernibles ($D(a, a) = 0$).
- **Cosine**: Bounded in $[0, 2]$, symmetric ($D(a, b) = D(b, a)$), identity of indiscernibles for non-zero vectors ($D(a, a) = 0$).
- **Inner Product**: Range $(-\infty, \infty)$ (distance can be negative), symmetric ($D(a, b) = D(b, a)$), no identity of indiscernibles ($D(a, a) = -\|a\|^2$).

## Testing Strategy
1. Unit tests with hand-computed vector pairs.
2. Property-based testing with `proptest` verifying symmetry for all metrics and $D_{L2}(a, a) = 0$.
3. Cross-validation against Python numpy golden dataset in `tests/golden/metrics.json` generated by `scripts/gen_metric_golden.py` with tolerance $\le 10^{-5}$.
4. Complete documentation in `docs/METRICS.md`.
