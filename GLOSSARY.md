# Systems Engineering Glossary: HNSW Filtered Vector Index

### HNSW
Hierarchical Navigable Small World graph structure providing logarithmic search complexity for approximate nearest neighbors.

### Single-Stage Filtering
Evaluating scalar metadata constraints directly during graph traversal rather than pre- or post-filtering.

### Cosine Distance
Metric measuring the cosine of the angle between two non-zero vectors in multi-dimensional space.

### Entry Point
The highest layer node in the HNSW multi-layer graph where hierarchical greedy search begins.
